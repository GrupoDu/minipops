# Minipops
Sistema desenvolvido para gerenciar **vendas, fornecedores, clientes, gastos, visualizar analise de vendas e gastos**.

## Tecnologias
- NextJS
- Typescript
- Prettier
- ESlint
- Axios
- Bun

## Como rodar
Primeiramente é necessário verificar se o bun está instalado no seu sistema.

Se não tiver certeza, visite o [site do bun](https://bun.sh/).

Com o bun instalado, rode:
```bash
# Instala as dependências
bun install

# Roda o projeto como dev
bun run dev
```

Após isso, acesse `http://localhost:3000`.
